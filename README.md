# STILL

Лендинг ретритов STILL на Next.js 16, React 19, TypeScript и Tailwind CSS 4.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Next.js. Чтобы собрать production-версию, используйте `npm run build`; собранный сайт запускается командой `npm start`.

Фотографии и шрифты хранятся локально в `public/images` и `public/fonts`.
